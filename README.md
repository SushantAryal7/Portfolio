# Portfolio Project

This is a **React-based Portfolio** that showcases my professional information, skills, and projects. It has an attractive and **responsive** design.

## Features
- **About Me**: Information about myself.
- **Skills**: List of technical skills.
- **Projects**: My key projects.
- **Contact**: Ways to contact me (Email, LinkedIn, GitHub, Phone).

## Technologies Used
- **React.js**
- **Tailwind CSS**
- **GitHub Pages** (for Deployment)
